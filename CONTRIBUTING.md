# Contributing

Thanks for helping improve CS2-Bot-Improver! Bug reports, code changes, documentation, and translations are all welcome.

## Issues and ideas

Check the [README](README.md) and existing [issues](https://github.com/ed0ard/CS2-Bot-Improver/issues) first, then use the bug report or feature request form. Keep each issue focused on one problem or idea.

For bugs, include your operating system, whether you are hosting a local game or a dedicated server, and the plugin and CounterStrikeSharp versions. Describe what happened, what you expected, and how to reproduce it. Relevant logs or a short video are helpful. If possible, check whether the same problem happens with the plugin disabled.

For ideas, explain the gameplay or usability problem you want to solve and the behavior you would like to see.

Please report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Pull requests

Small fixes are welcome directly. For larger behavior changes, please open an issue first so we can agree on the direction.

- Start a branch from the latest `main` and keep the change focused.
- Follow the style of the code you touch and keep unrelated cleanup separate.
- Explain what changed, why it helps, and how you tested it.
- For code changes, build the affected component and test it in CS2 when possible. Mention the platform you tested and anything you could not verify.
- Update relevant documentation when changing commands, settings, or installation steps.
- Leave local configs, logs, and generated build output out of the PR unless they are needed for the change.

You do not need a perfect solution to start a discussion. A clear example or a small improvement is a useful contribution.
