# Security

## Reporting a vulnerability

If you find a security issue in CS2-Bot-Improver, please use GitHub's private [Report a vulnerability](https://github.com/ed0ard/CS2-Bot-Improver/security/advisories/new) form. Keep exploit details out of public issues and pull requests while we investigate.

Please include:

- The affected version and component, such as a plugin or the Windows Panel.
- Your operating system and relevant dependency versions.
- Steps to reproduce the issue or a small proof of concept.
- The possible impact and any conditions needed to trigger it.

Remove passwords, tokens, and other private information from attached logs or files. We can discuss further details and a fix in the private report.

## Versions

Please check the [latest release](https://github.com/ed0ard/CS2-Bot-Improver/releases/latest) when possible. If you found the issue in an older release or a source build, include the version or commit so we can identify the affected code. You can still report it if you cannot test the latest version.

For other problems with no security impact, please use [Issues](https://github.com/ed0ard/CS2-Bot-Improver/issues).
